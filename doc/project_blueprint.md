# Telegram Folder Manager (v2.0)

Автоматизация управления папками (folders) Telegram. Скрипт позволяет автоматически сортировать чаты и каналы по папкам, основываясь на шаблонах и исключениях, а также экспортировать структуру папок в YAML файл. Также поддерживает суммаризацию чатов с помощью LLM.

**Внимание: Эта версия (2.0) прошла через масштабный рефакторинг архитектуры.**

---

## Основные изменения в версии 2.0

- 🏗 **Новая архитектура:** Полное разделение ответственности (Separation of Concerns) между инфраструктурой и бизнес-логикой.
- 🛡 **Валидация конфигурации:** Использование `Pydantic` для строгой проверки `config.yaml`.
- 🧩 **Модульность:** Выделены отдельные компоненты для логики сопоставления (`matcher.py`) и моделей данных (`models.py`).
- 🔌 **Dependency Injection:** Конфигурация передается в компоненты явно, что облегчает тестирование.
- 🚀 **Поддержка суммаризации:** Добавлен модуль `tg_summarise_chat` для создания резюме чатов через LLM (LM Studio, GigaChat).

- ✅ Автоматическая сортировка чатов по папкам на основе паттернов
- ✅ Поддержка исключающих шаблонов для точного контроля

- ✅ Гибкие стратегии обработки несопоставленных чат
- ✅ Обнаружение дубликатов (чатов в нескольких папках)

### 📝 Суммаризация чатов
- ✅ Создание краткого резюме текущего дня

## Использование

### 1. Настройка
Создайте файл `config.yaml` (возьмите пример из `config.yaml.example` или создайте сами) и заполните ваши API ID, API Hash и настройки LLM/Прокси.
Подробнее о структуре конфигурации: [doc/CONFIGURATION.md](doc/CONFIGURATION.md)

Поддерживаются следующие типы прокси:
- `socks5`
- `http`
- `mtproto`

#### **Раздел `summarizer` (Настройки LLM)**
Этот раздел позволяет тонко настроить поведение модели при создании резюме:
- `model`: Название модели (например, `gpt-4` или `google/gemma-4`).
- `base_url`: URL адрес API (например, `http://localhost:1235`).
- `temperature`: Параметр "креативности" (0.0 - 1.0).
- `max_tokens`: Максимальное количество токенов в ответе.
- `timeout_seconds`: Тайм-аут ожидания ответа от API.
- `system_prompt`: (Опционально) Системная инструкция, определяющая роль и правила поведения модели.
- `user_prompt_template`: (Опционально) Шаблон промпта для пользователя. Должен содержать плейсхолдер `{text}` для вставки текста чата.

**Пример:**
```yaml
summarizer:
  model: "gemma-4"
  base_url: "http://localhost:1234/v1"
  temperature: 0.7
  max_tokens: 2048
  system_prompt: "Ты профессиональный ассистент, который создает краткое резюме диалога. Выделяй ключевые моменты, решения и действия. Форматируй ответ с использованием маркированных списков. Ответ должен быть строго на русском языке."
  user_prompt_template: "Создай краткое резюме:\n\n{text}"
```

### 2. Управление папками (по умолчанию)
Запустите скрипт для автоматической сортировки чатов:
```bash
python tg_tool.py
```
