# Security Policy

## Supported Versions

We actively support the current version of **Telegram Folder Manager**.

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | Yes                |
| < 2.0.x | No                 |

## Reporting a Vulnerability

**⚠️ IMPORTANT: DO NOT report security vulnerabilities through public GitHub Issues. Reporting a vulnerability through public channels may expose users to attacks before a fix is available.**

If you find a security vulnerability, please report it to us immediately via one of the following methods:

### 1. Email Reporting
Please send a detailed report to **[sky1su_at_ya.ru]**. 
In your email, please include:
- A description of the vulnerability.
- Steps to reproduce the issue (including code snippets or screenshots if applicable).
- The potential impact of the vulnerability.

### 2. GitHub Private Vulnerability Reporting
If you are using GitHub, you can use the **Private Vulnerability Reporting** feature if it is enabled for this repository. This allows you to report issues directly to the maintainers without making them public.

## Our Response Process

Once we receive a report, our process is as follows:
1. **Acknowledgment**: We will acknowledge receipt of your report within a reasonable timeframe.
2. **Triage**: We will investigate and confirm the validity of the vulnerability.
3. **Fixing**: We will work on developing a fix/patch as quickly as possible.
4. **Disclosure**: Once the fix is released, we will notify you and, if appropriate, credit you for the discovery.
